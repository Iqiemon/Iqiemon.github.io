          Automation, Python, ADB. Private.

          Python on Windows drives a wallet app inside BlueStacks over ADB to work through a queue of payment jobs, replacing a rooted-phone Tasker setup.

          1. Claim job
          2. Unlock app
          3. Paste code
          4. Confirm PIN
          5. Report result
          • Runs several emulator instances in parallel; the server claims jobs with FOR UPDATE SKIP LOCKED so two instances never take the same job.
          • Reports success or releases the job on failure, so nothing is stuck.
          • Also includes a Telegram alert watcher that scans a reservation widget for open slots.

          Python, ADB, BlueStacks, REST, Telegram
